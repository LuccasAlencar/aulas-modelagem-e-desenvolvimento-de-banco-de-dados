    📚 Aula 1: Introdução à modelagem de banco de dados

    🎯 Objetivos de Aprendizagem

    • Conhecer os conceitos fundamentais de modelagem de banco de dados, incluindo a importância dos bancos de dados, os diferentes tipos e os componentes principais que os constituem.
    • Conhecer os conceitos fundamentais de modelagem de banco de dados, incluindo a importância dos bancos de dados, os diferentes tipos e os componentes principais que os constituem.
    • Estimular a curiosidade ao explorar os conceitos básicos de modelagem de banco de dados e entender a importância dos bancos de dados nos sistemas de informação.

    ⏱️ Cronograma da Aula

    Tempo Atividade Descrição
    0-10min Introdução A modelagem de dados surgiu da necessidade de organizar e gerenciar de forma eficiente as crescentes quantidades de dados que as empresas começaram a acumular a partir da segunda metade do século XX.
    10-25min Conteúdo Principal Tipos de bancos de dados, componentes principais, modelagem de banco de dados
    25-40min Simulação de banco de dados Dividam-se em grupos e escolham um dos seguintes cenários: biblioteca, loja on-line, hospital ou escola.
    40-55min Discussão em classe Quais seriam as entidades principais para o cenário escolhido?
    55-70min Atividade prática Criem tabelas com as entidades e seus atributos, desenhando as colunas e linhas, e preencham alguns exemplos fictícios para cada entidade.
    70-85min Fechamento Resumo e próximos passos

    📖 Conteúdo da Aula

    1️⃣ Introdução (10 min)

    💬 DISCUSSÃO EM CLASSE: Como a modelagem de dados contribui para a otimização das consultas e relatórios? (ex.: performance, agilidade, precisão).

    2️⃣ Desenvolvimento (30 min)

    Conceito Chave: Tipos de Bancos de Dados

    • Bancos de dados relacionais (RDBMS): ideais para aplicações que exigem alta integridade de dados, transações complexas e consultas estruturadas, como sistemas financeiros e ERP.
    • Bancos de dados não relacionais (NoSQL): ideais para aplicações que exigem alta escalabilidade, flexibilidade para diferentes tipos de dados e alta performance em operações de leitura, como sistemas de recomendação, análise de logs e IoT.

    Conceito Chave: Componentes Principais dos Bancos de Dados

    • Armazenam dados em documentos JSON ou XML (e.g., MongoDB).
    • Software que gerencia e manipula o banco de dados. Exemplos incluem Oracle, SQL Server, MySQL e PostgreSQL.
    • Estruturas que armazenam os dados em linhas e colunas (nos bancos de dados relacionais).

    Conceito Chave: Modelagem de Banco de Dados

    • A modelagem de banco de dados é o processo de criar um modelo para a estrutura dos dados. Inclui: modelagem conceitual, modelagem lógica e modelagem física.

    📊 EXEMPLO PRÁTICO: Caso real de modelagem de banco de dados.

    🤔 PAUSA PARA REFLEXÃO: Qual é o papel da modelagem de dados na integração de diferentes sistemas? (ex.: padronização, compartilhamento de informações).

    4️⃣ Fechamento (5 min)

    • ✅ Tipos de bancos de dados: relacionais e não relacionais.
